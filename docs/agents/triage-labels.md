# Triage labels

Canonical labels used by the triage skill:

- `needs-triage`: newly opened issue awaiting first evaluation
- `needs-info`: blocked on information from the author or a third party
- `ready-for-agent`: scoped, specified, and ready for autonomous agent execution
- `ready-for-human`: requires human decision, credential access, or manual validation
- `wontfix`: decided against; closed without code changes
